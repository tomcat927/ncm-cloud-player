# 返回键延迟调查（待跟进）

## 现象

MIUI 设备上，播放详情页（含暂停状态）按系统返回键（三大金刚），偶发 **2-4 秒无响应**才回到云盘列表；期间点击左上角"收起"也无响应。非必现。

## 设备与环境

- 设备：Redmi K60（Xiaomi 23049RAD8C），Android 13 (SDK 33)，MIUI/HyperOS
- App：v0.1.0 (2026-10-02 构建起为带全套探针的版本)
- 复现条件：详情页停留（播放中或暂停均有疑似样本），返回键偶发延迟

## 已证实的结论（三层探针实测，多轮日志一致）

1. **App 内处理是毫秒级**：返回键到达 → Compose 处理（2-4ms）→ 页面拆除（15-20ms）→ 列表首帧渲染（+13-29ms），六次以上复现全部即时；
2. **主线程从未阻塞**：1 秒心跳全程规整（±5ms）；
3. **延迟发生在"按键到达 App 之前"**——即系统派发层；
4. **卡顿时刻伴随窗口焦点被抢**（`窗口焦点: hasFocus=false` 持续 1.4-1.5s 后恢复）：焦点在系统层手里时，按下的返回键被 MIUI 截走、**不会送达 App**（日志无该次按键记录），用户感知为"点了没反应"，焦点恢复后重按即正常。

## 已尝试

- `enableOnBackInvokedCallback="true"`（现代回调路径）：MIUI Android 13 上反而触发预测性返回抢焦点（实测日志），**已撤回**；
- 关闭开发者选项"返回手势动画"（=预测性返回）：焦点抢夺**仍偶发**，非该选项单独导致。
